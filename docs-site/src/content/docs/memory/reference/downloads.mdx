# Downloads and checksums

The latest memory monorepo release is **{downloads.version}**, released on **{downloads.released}**. Binaries are published as GitHub Release assets at `yakovkhalinsky/eden-releases`.

The monorepo ships two binaries:

- **`memory`** — the full CLI with MCP server, memory tools, sync, and pairing.
- **`relay`** — a dedicated, lightweight relay server with no MCP or memory subcommands.

## Quick install

The recommended installer defaults to `memory`. Pass a binary name to install `relay` instead:

```bash
# Default: install memory
curl -fsSL https://0d3sa.com/memory/install.sh | sh

# Install the dedicated relay binary
curl -fsSL https://0d3sa.com/memory/install.sh | sh -s relay
```

The installer places the binary at `~/.local/bin/<binary-name>`.

## Manual install

If you prefer to download and verify manually, replace `BINARY` with `memory` or `relay` and `PLATFORM` with your platform key from the tables above:

```bash
VERSION={downloads.version}
BINARY=memory
PLATFORM=linux-amd64
FILENAME=${BINARY}-${PLATFORM}

wget https://github.com/yakovkhalinsky/eden-releases/releases/latest/download/${FILENAME}
wget https://github.com/yakovkhalinsky/eden-releases/releases/latest/download/${FILENAME}.sha256
sha256sum -c ${FILENAME}.sha256

mkdir -p ~/.local/bin
mv ${FILENAME} ~/.local/bin/${BINARY}
chmod +x ~/.local/bin/${BINARY}
```

## Release build targets

From the `memory` repository source tree:

```bash
make release       # memory for linux-amd64/arm64, darwin-amd64/arm64
make release-relay # relay for linux-amd64/arm64, darwin-amd64/arm64
make release-all   # both of the above
```

This produces `dist/memory-<platform>` and `dist/relay-<platform>` for each supported platform.

## Verify the binary

After installing:

```bash
memory version
memory health
```

For `relay`:

```bash
relay --db /var/lib/relay/relay.db --addr 127.0.0.1:8787 &
curl http://localhost:8787/health
```

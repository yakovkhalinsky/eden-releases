# Downloads and checksums

The latest eden-memory release is **{downloads.version}**, released on **{downloads.released}**. Binaries are published as GitHub Release assets at `yakovkhalinsky/eden-releases`.

## Quick install

The recommended install uses the curl installer, which downloads the right binary for your platform and verifies its checksum:

```bash
curl -fsSL https://0d3sa.com/eden-memory/install.sh | sh
```

The installer places the binary at `~/.local/bin/eden-memory`.

## Manual install

If you prefer to download and verify manually:

```bash
VERSION={downloads.version}
PLATFORM=linux-amd64
FILENAME=eden-memory-${PLATFORM}

wget https://github.com/yakovkhalinsky/eden-releases/releases/latest/download/${FILENAME}
wget https://github.com/yakovkhalinsky/eden-releases/releases/latest/download/${FILENAME}.sha256
sha256sum -c ${FILENAME}.sha256

mkdir -p ~/.local/bin
mv ${FILENAME} ~/.local/bin/eden-memory
chmod +x ~/.local/bin/eden-memory
```

Replace `linux-amd64` with your platform key from the table above.

## Verify the binary

After installing:

```bash
eden-memory version
eden-memory health
```

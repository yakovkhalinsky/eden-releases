## Overview

eden-memory is the private source repository for the eden agent harness. This public site hosts releases, documentation, and ready-to-use agent skills.

## Quick start

1. Clone the release repo:
   ```bash
   git clone https://github.com/yakovkhalinsky/eden-releases.git
   ```
2. Follow the installation notes for your platform in the release assets.
3. Import the skills under `skills/` into your agent environment.

## What's published here

- Release notes and changelogs
- Packaged agent skills
- Reference documentation for public interfaces
